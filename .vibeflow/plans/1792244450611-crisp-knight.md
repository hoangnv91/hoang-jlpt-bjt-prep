## Kiến trúc hệ thống (bổ sung vào v1)

```
┌─────────────────────────────┐   ┌──────────────────────────────┐
│ Next.js 15 (App Router)     │   │ Worker (node scripts/worker) │
│ - UI: ingest, review, learn │   │ - consume ProcessingJob      │
│ - API routes (REST)         │──▶│ - extract → chunks → AI      │
│ - Auth.js + authz per-object│   │ - rights-check               │
└────────────┬────────────────┘   └──────────────┬───────────────┘
             │                                   │
             ▼                                   ▼
      ┌───────────────┐   ┌───────────────┐   ┌───────────────┐
      │ PostgreSQL    │   │ MinIO (S3)    │   │ AI provider   │
      │ (Prisma)      │   │ private files │   │ (OpenAI-      │
      └───────────────┘   └───────────────┘   │  compatible)  │
                                              └───────────────┘
```

- **Storage**: interface `lib/storage.ts` — impl S3 (MinIO trong compose) + fallback local disk (volume riêng, private). Upload luôn private, không public URL.
- **Worker**: tiến trình nền riêng đọc bảng `ProcessingJob` (polling), có state machine + retry policy. Chạy trong compose như service riêng.
- **AI provider**: client OpenAI-compatible qua env (`AI_API_KEY`, `AI_BASE_URL`, `AI_MODEL`), output **JSON có schema** (zod validate), prompt templates trong `lib/ai/prompts/`.
- **Queue**: dùng bảng `ProcessingJob` làm queue (đơn giản, không thêm infra); worker poll theo interval + backoff.

## Data model (bổ sung — đầy đủ cho v2)

```
User (v1) — sở hữu mọi thứ
Document         id uuid, userId, fileName, mimeType, sizeBytes, sha256,
                 storageKey, sourceType: UPLOAD|URL|TEXT, sourceUrl?,
                 author?, license?, rightsStatus: UNKNOWN|PERMITTED|RESTRICTED|PENDING_VERIFICATION,
                 rightsVerifiedAt?, rightsEvidence?, purpose, status: PROCESSING|READY|FAILED,
                 createdAt (UTC)
SourceChunk      id uuid, documentId, index, page?, paragraph?, heading?,
                 content, charStart?, charEnd?
ProcessingJob    id uuid, userId, documentId?, type: EXTRACT|RIGHTS_CHECK|AI_GENERATE,
                 status: PENDING|RUNNING|SUCCEEDED|FAILED|CANCELLED,
                 attempts, maxAttempts, nextRetryAt?, errorCode?, errorMessage?,
                 startedAt?, finishedAt?, createdAt (UTC)
AiDraft          id uuid, userId, documentId?, sourceChunkIds[], kind: VOCAB|GRAMMAR|READING|QUESTION|LESSON,
                 payload Json (structured), sourceRefs Json, status: PENDING_REVIEW|ACCEPTED|REJECTED,
                 aiModel, createdAt, reviewedAt?
Lesson           id uuid, userId, title, content Json, sourceRefs Json, status: PUBLISHED,
                 roadmapOrder?, createdAt — CHỈ tạo từ draft ACCEPTED
Question         (v1) + documentId?, draftId?, sourceChunkIds[] — CHỈ tạo từ draft ACCEPTED
RoadmapItem      id uuid, userId, lessonId, order, title, status: PLANNED|IN_PROGRESS|DONE
Flashcard/QuizAttempt/AttemptAnswer (v1)
```

- Rights model: phân biệt 4 quyền trên Document: `rightsStore` (lưu trữ), `rightsExtract` (trích xuất), `rightsSendAI` (gửi AI), `rightsDistribute` (phân phối) — mỗi quyền: PERMITTED | NOT_PERMITTED | UNKNOWN.

## Luồng xử lý bắt buộc (state machine)

```
Input (upload/URL/text)
  → 1. Validate input (zod + magic bytes + size + SSRF guard)
  → 2. Tạo Document metadata + ProcessingJob(EXTRACT) [PENDING]
  → 3. Evaluate usage rights (RIGHTS_CHECK) — không tự suy luận "tải được = được dùng"
  → 4. Extract & normalize nội dung ĐƯỢC PHÉP → SourceChunks (kèm page/paragraph)
  → 5. AI sinh bản nháp (VOCAB/GRAMMAR/READING/QUESTION/LESSON) — output validate schema + verify sourceRefs
  → 6. Lưu AiDraft status=PENDING_REVIEW (KHÔNG tự động public/phân phối)
  → 7. User duyệt: EDIT / ACCEPT / REJECT từng bản nháp
  → 8. Chỉ draft ACCEPTED → tạo Lesson/Question
  → 9. (Tùy chọn) Thêm Lesson vào Roadmap
```

Job state machine: `PENDING → RUNNING → SUCCEEDED | FAILED | CANCELLED`; retry policy: tối đa 3 lần, backoff exponential (1s→5s→30s), `nextRetryAt`; lỗi vĩnh viễn (validation, rights RESTRICTED) → FAILED không retry.

## Tính năng chi tiết v2

### 1. Ingestion (lib/ingest/)
- Upload file: **PDF, DOCX, TXT, Markdown, CSV** (giới hạn 20MB).
- Nhập **URL công khai** (fetch có SSRF guard).
- Nhập **văn bản thủ công** (paste text).
- Mỗi nguồn điền metadata: tác giả/chủ sở hữu, giấy phép/điều khoản, mục đích sử dụng, trạng thái quyền + bằng chứng + thời điểm xác minh.

### 2. Extraction & normalization (lib/extract/)
- PDF → `pdf-parse`; DOCX → `mammoth`; TXT/MD → text; CSV → parse thành bảng.
- Chuẩn hóa → `SourceChunk` kèm **vị trí** (page/paragraph/heading, charStart/End khi xác định được).
- Không bao giờ thực thi file/macro; chỉ đọc text.

### 3. Copyright & provenance (lib/rights/)
- Lưu URL nguồn, tác giả, license, trạng thái quyền, bằng chứng, thời điểm xác minh.
- Phân biệt 4 quyền (store/extract/send-AI/distribute).
- **Không suy luận** "tải miễn phí = được dùng" / "chỉ học tập cá nhân = được dùng".
- Rights UNKNOWN/PENDING_VERIFICATION → giữ để xem xét, không tự động public.
- **Không sao chép toàn bộ sách có bản quyền / ngân hàng đề / đoạn dài** khi chưa có quyền: giới hạn trích xuất theo rightsExtract + mục đích.

### 4. AI draft generation (lib/ai/)
- Prompt templates: `vocab.md`, `grammar.md`, `reading.md`, `question.md`, `lesson.md` — mỗi template yêu cầu output JSON schema (zod).
- Draft luôn gắn `sourceRefs` (documentId + chunkIds + vị trí).
- Nội dung tài liệu coi là **untrusted input** khi gửi AI (sanitize, không prompt-inject).
- Budget AI: giới hạn số request/ngày/user + timeout mỗi request.

### 5. Review UI (app/(main)/review/)
- Danh sách draft theo trạng thái; xem draft kèm source chunks + sourceRefs.
- Nút **Chỉnh sửa / Chấp nhận / Từ chối** từng draft.
- Chỉ ACCEPTED mới tạo Lesson/Question (transaction).

### 6. Learning roadmap (app/(main)/roadmap/)
- Tạo roadmap, thêm Lesson (từ draft đã duyệt), sắp xếp thứ tự, đánh dấu trạng thái.

- **SSRF guard** (lib/security/ssrf.ts): chỉ http/https, chặn redirect, chặn private/loopback/link-local IP ranges, timeout fetch. Test SSRF.
- **Không thực thi** file/macro upload.
- **Logging**: tuyệt đối không ghi toàn bộ text tài liệu, credential, secret vào log.

- **Xóa dữ liệu**: endpoint xóa Document → cascade xóa chunks/drafts/lessons/queries + xóa file storage. Test xóa.
